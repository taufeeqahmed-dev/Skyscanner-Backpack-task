Skyscanner Backpack React Web App 

A React web application built using Skyscanner's Backpack design system as part of the Skyscanner Software Engineering Job Simulation on Forage.

Overview

The objective of this task was to use Skyscanner's Backpack component library to build a simple travel reservation date-selection interface.

The application allows a user to:

- View a calendar
- Navigate between months
- Select a date
- Interact with a Skyscanner Backpack-based interface

The task also introduced automated testing as part of the development workflow.

Technologies Used:

- React
- JavaScript
- HTML
- SCSS
- Skyscanner Backpack Web
- Node.js
- npm
- React Testing Library
- Git
- GitHub

Backpack Components

The application uses components from Skyscanner's Backpack design system, including:

- `BpkCalendar`
- `BpkText`
- Backpack React utilities and styling

Backpack provides reusable components and design guidelines used to create consistent Skyscanner interfaces.
